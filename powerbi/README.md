# 📊 Power BI Dashboard

This folder contains the Power BI components for the Loan Risk & Fraud Analytics project.

---

## 🧩 Data Model  

A relational data model was developed in Power BI to integrate:
- Loan applications  
- Customer profiles  
- Transactions  
- Risk assessment data  

This structure enables accurate KPI calculations and supports analysis across risk, fraud, and customer dimensions.

![Data Model](screenshots/data_model.png)

---

## 📈 Dashboard Overview  

The dashboard consists of four main sections:

- Executive Summary → Portfolio performance and KPIs  
- Credit Risk Analysis → Risk distribution and default trends  
- Fraud Detection → Fraud patterns and anomalies  
- Customer Overview → Customer-level insights  

---

## 📊 DAX KPIs  

Key DAX measures were created to calculate:
- Approval Rate  
- Default Rate
